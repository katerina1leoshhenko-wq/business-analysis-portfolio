# Business Analysis Portfolio

Selected business analysis case studies focused on process discovery, BPMN 2.0 modelling, regulatory process formalization, and transition from document-heavy workflows to structured digital processes.

This repository is intentionally compact. It contains short portfolio summaries, while detailed diagrams and source artifacts are kept in separate case repositories.

## Featured Cases

### BA Case 01: Paper-Based Document Handover to CDE Workflow

Analysis of a construction documentation handover process in road infrastructure. The case compares an AS-IS paper-based workflow with a TO-BE process using a Common Data Environment, electronic signatures, version control, and traceable document status.

**Demonstrates:** AS-IS discovery, bottleneck analysis, TO-BE process design, BPMN 2.0 modelling, and requirements analysis.

Detailed BPMN diagrams and source artifacts are available upon request.

### BA Case 02: Regulatory Text to BPMN 2.0 Process Model

Formalization of a regulatory process from semi-structured text into BPMN 2.0 and supporting UML/PlantUML views. The case focuses on extracting process logic from a technical standard, validating AI-assisted outputs, and turning ambiguous prose into structured process models.

**Demonstrates:** regulatory analysis, AI-assisted extraction, analyst validation, BPMN semantics, and decomposition of complex documentation flows.

Detailed BPMN diagrams, PlantUML views, and source artifacts are available upon request.

### BPMN Grid Layout Kit

Python tool for reproducible BPMN-DI layout based on a YAML grid description. The project supports repeatable diagram formatting and separates BPMN business semantics from visual layout coordinates.

**Demonstrates:** automation mindset, BPMN-DI understanding, structured configuration, and practical tooling for process modelling.

Full project: [bpmn-grid-layout](https://github.com/katerina1leoshhenko-wq/bpmn-grid-layout)
